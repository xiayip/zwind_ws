# 静场 AEC 复测与已固化语音基线（2026-11-18 夜间）

## 结论

当前语音基线已提交并打标签。夜间静场复测仍能复现 **麦克风持续上传时，机器人回声触发“有人讲话”，截断自己的播报**。参考对齐、降噪、AEC3、关闭云端自动增益均未得到可靠通过的组合，未将实验参数部署到 HMI。

HMI 保留用户已验收的轮流讲话模式、650 ms 播放尾音保护和默认 80% 音量。所有临时采录节点已退出；服务健康，页面空闲，订单仍为演示模式。安静测试不能验证真实用户插话是否被保留，本次不宣称实现了全双工。

## 方法与边界

- 用户明确授权离场后的持续安静测试。没有独立仪器确认声场；按该条件解释记录。
- USB ReSpeaker Lite，两路麦克风样本完全相同。系统 USB 播放和采集均报告 16 kHz、双声道、S16_LE，未发现 48/16 kHz 格式错配。
- 使用实际 `played` 参考、USB `mic` 与软件处理后 `clean`，保存样本及消息时间戳。USB mic 已经过板载处理，**不是未经处理的原始麦克风**。
- 本地对照播放同一段约 8.75 秒中文语音，通常连续三遍，中间约 2 秒间隔。默认 80% PCM 音量；仅一个独立进程以 40% 做对照。
- 云端测试使用隔离 LiveKit 房间和固定朗读任务。诊断客户端显式关闭上传静音保护，`full_duplex=true`，上传实际 clean；没有用生产播放门控掩盖回声。
- 本地录音留在设备，未另行上传录音文件；云端三轮按授权实时上传净化麦克风。没有保存云端测试的麦克风音频，只保存电平统计、接收与播放参考。
- 实验未改生产源码、安装目录、板载固件或系统音频库。AEC3 使用 `/tmp` 独立构建及 ROS overlay；每次硬件测试串行运行。

## 本地对照结果

以下为每遍播放期间及 650 ms 尾段的 clean RMS，单位 dBFS，越负越小。不同录制轮次仍可能受到设备处理状态影响，不能把差异全部归因于参数。数值是总电平，**不是严格 ERLE，也不证明近端人声完整**。

| 配置 | 第一遍 | 第二遍 | 第三遍 |
| --- | ---: | ---: | ---: |
| 基线 0.3.1、80% | -20.15 | -21.55 | — |
| 参考后移 200 ms | -21.24 | -24.39 | -28.67 |
| 后移 200 ms、时间戳连续化 | -21.65 | -24.90 | -29.43 |
| 后移 280 ms、时间戳连续化 | -28.06 | -26.73 | -25.89 |
| AEC3 默认配置 | -19.02 | -21.48 | -20.56 |
| 后移 300 ms、时间戳连续化、降噪 | -26.04 | -30.77 | -31.33 |
| 上述配置、实验音量 40% | -24.36 | -32.07 | -33.10 |

300 ms + 降噪在 80% 下相对 USB mic 的总电平下降为 10.15 / 14.87 / 15.35 dB；首遍前 3 秒 clean 仍为 -21.36 dBFS。40% 的首遍前 3 秒为 -20.17 dBFS，并未改善冷启动残留。不能仅根据后两遍平均电平选择生产参数。

另以同一份录音离线比较三个算法模式、0–400 ms（20 ms 步长）参考偏移，共 63 组。部分参数改善第一遍，却恶化后续遍次；没有得到跨遍次稳定最优的延迟。该扫描是辅助探索，不能代替实时 ROS/云端验证。

## 云端判定

三轮均为麦克风上传开启、播放静音保护关闭、80% 输出，现场按用户约定保持安静：

| 配置 | 云端检测人声 | 固定播报被截断 |
| --- | --- | --- |
| 基线 AEC、云端 AGC 开 | 是 | 是 |
| AEC3、云端 AGC 开 | 是 | 是 |
| 300 ms 对齐 + 时间戳连续化 + 本地降噪、云端 AGC 关 | 是 | 是 |

最后一轮上传电平 P50 / P90 / P99 为 -45.61 / -20.75 / -11.11 dBFS。中位数降低并没有消除较强残留和误触发。原始结果摘要见 `artifacts/aec-quiet-20261118/live-results.json`。

## 进一步定位的线索

1. 部分启动轮次有 PortAudio 输入溢出和消息时间戳间隙。把时间戳按连续样本数平滑后仍有回声残留，不能把问题仅归因于调度抖动。
2. 语音波形与麦克风的相关峰较弱，观测偏移约 341–346 ms。它不是硬件 ADC/DAC 延迟的直接测量，不能据此写死全局延迟。
3. 40% 播放相较 80% 数字幅度减半，USB 麦克风总电平只降低约 1–1.4 dB，首遍净化效果没有改善。可能与板载动态处理、背景声、声学路径等有关，不能据此单独断定功放削波。
4. 180/400/800 Hz 固定音测试中，400 Hz 的 USB mic 二次谐波比基频高约 9.8 dB，800 Hz 的三次谐波比基频高约 12.2 dB；播放参考没有相应强谐波。由于麦克风已经过板载 AEC/降噪，它可能已抑制基频；这些数字不是扬声器 THD。只说明仍有非线性或板载处理后的残留值得排查，不能定位到某一硬件。
5. 两个 USB 麦克风通道完全相同，没有可供本次软件切换的独立原始通道。

下一步应优先取得可控的板载处理/原始麦克风对照，或用另一套麦克风与喇叭验证声学路径，并使用真实人声检验双讲保护；继续只提高 VAD 阈值或加强降噪可能同时损伤近端讲话。本次没有进行固件刷写或未经验证的全双工上线。
