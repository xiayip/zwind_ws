# GMSL 左前相机与 RTC token 启动故障验证

2026-11-19，Asia/Shanghai。Jetson J401，内核 `6.8.12-1021-tegra`，
ROS 2 Jazzy，容器 `zephyr_dev_24.04-aarch64-container`。

## 左前相机：插拔后串行器地址丢失

用户确认只有左前相机接口插拔过。17:41 单独启动 `/dev/video11`，仍出现
`start V4L2 stream: Remote I/O error`。内核对应 `max96717 10-0040`
访问 `0x0002`、`0x0318`、`0x02d3` 失败，错误码 `-121`。
其他相机未运行，因此这次失败不依赖四路同时启动。

停止采集后的定向读取（不扫描整个 I²C 总线）：

| 总线 2 的串行器地址 | 设备 ID 寄存器 0x000d | 状态 |
| --- | --- | --- |
| 0x40 | 0xc8 | 默认地址出现设备，地址寄存器 0x0000 = 0x80 |
| 0x41 | 0xc8 | 正常 |
| 0x42 | Remote I/O error | 左前分配地址失效 |
| 0x43 | 0xc8 | 正常 |
| 0x44 | 0xc8 | 正常 |

设备树 `i2c-alias-pool` 为 `0x41 0x42 0x43 0x44`。四路 GMSL 的
link-lock 位都置位，说明恢复链路锁定并没有恢复串行器地址。
[Seeed R39.2 BSP 的地址分配实现](https://github.com/Seeed-Studio/Linux_for_Tegra/blob/c018d61c5feb7951a16317b03ec9e0be6d6cb8cb/source/nvidia-oot/drivers/media/i2c/maxim-serdes/max_des.c)
在初始化时复位串行器并重新分配地址；现有 ROS 组件重启不会重走这个流程。
结合插拔历史，证据支持相机端重新上电后回到默认地址、内核仍保留旧映射。
没有进一步区分插拔过程中供电变化和复位信号的电气细节。

重复 STREAMON 还出现返回成功但无图像、内核持续 VI timeout 的情况。
因此没有加入盲目重试或将 STREAMON 成功视为健康的改动。

17:47:54 主机发生重启；随后四个逻辑 I²C 总线 9/10/11/12 的设备 ID
均恢复 `0xc8`。准备的手工改址/重新绑定操作尚未执行，恢复来自主机重启。
当前处理方式是连接就绪后重启主机；本次没有实现 BSP 热插拔自动恢复，
也没有修改内核模块。相机 README 已补充排障方法。

## RTC：首次超时后缺少重试

原实现同步阻塞组件构造、HTTP 超时 10 秒，失败后不再连接。它与 Orbbec
共享容器，也会延迟后续组件加载。三次独立真实 token 请求均返回 HTTP 200，
耗时约 2.40 / 1.57 / 0.97 秒，未观察到凭据拒绝。
后端域名解析为 `198.18.31.174`，经 Wi-Fi 网关 `192.168.88.1` 路由；
不能据此确定最初超时发生在代理、外网还是服务端。

修改 `teleop_rtc_cpp`：异步获取 token；一次只执行一个请求；失败后按
1、2、4、8、16、30 秒退避；每次重新获取 token；成功连接后停止启动重试。
保留 HTTP 10 秒上限，关闭时等待正在执行的请求结束。

验证：

- 包编译通过。
- `test_json_status` 与新增 `test_initial_connection` 通过。
- 新测试依次模拟 HTTP 503、不完整响应、RTC 连接失败和成功；验证退避、
  构造不请求网络、HTTP 等待期间 executor 继续处理定时器，以及成功后不再请求。
- 完整 `z2_launch_all.launch.py` 运行 90 秒，只将 token URL 指向本机测试代理。
  代理故意让首次请求等待 11 秒触发客户端超时，第二次转发到真实后台。
  日志确认第一次超时后第二次连接 LiveKit 成功。
  测试代理不保存 token 或 API key。
- 实际启用并订阅四路相机，全部收到 1920×1080 RGB8 图像，每帧 6,220,800 字节；
  约 5 秒观察窗口内 CameraInfo 分别收到 119 / 100 / 111 / 108 条。
  这是订阅端计数，不当作无丢帧或精确采集帧率的证明。
- 底盘和机械臂硬件均 active；常用底盘、关节、轨迹、位置适配与夹爪控制器 active。
- 90 秒运行阶段没有 ERROR；测试结束后全部测试进程退出。
  SIGINT 退出阶段仍有既存异常：`vr_joy_mapper` 重复 shutdown 后退出码 1、
  `move_group` 退出码 -11，以及 controller_manager 的统计发布线程在 context
  失效后报错。这些退出问题本次未修改，不能将结果描述为整机全程无错误。

原始日志和测试工具在 `artifacts/media-startup-validation-20261119/`。
HMI 电池布局独立完成，提交 `ec8374a` 已推送到 HMI 仓库 `main`；
RTC 和相机排障文档没有随 HMI 一起合并。
